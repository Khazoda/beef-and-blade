# 🥩 Beef & Blade ⚔️

**Beef & Blade can be used serverside only, and will work with vanilla clients. Please report any problems/bugs to the issue tracker.**

Since version 1.1.0, Beef & Blade is available as a datapack (or datapack wrapped as a mod)

## What this datapack does
Leather is used in a huge number vanilla and modded recipes, yet is hard to reliably get early-game.

**Beef & Blade** rebalances cow drops by letting the player pick what resources they need from a cow by using different weapons.

Drop values can be fully customized in the mod's config file.
